# The cell contract and the generation's files (Day 1, 2026-09-30; his NEXT-WEEK.md loop, steps 1 to 8)

Every part of the loop reads this file. It is the interface four builders built against in parallel, so a
change here is a change to all of them: add, never rename.

## A cell

A cell is one ES module, `cell.mjs`, self contained: no import except a relative `./x.mjs` inside its own
directory, no `node:` module, no bare specifier, no `require`, no dynamic `import()`, no `fetch`, no
`process`, no `eval`, no `new Function`, no timers. Pure and synchronous: the same `q` gives the same
answer. Under 512 KB of source. It exports:

- `meta`: `{ id, class, generation, lane, grownFrom, version: 1 }`. `id` matches `^[a-z0-9][a-z0-9-]{2,63}$`
  and is unique across the store; `class` is the failure class it grew for (`fragment`, `mash`,
  `capital-of`, `essay-ocean-salt`, ...); `generation` an integer from 1; `lane` a short word;
  `grownFrom` the prompts it was grown from (strings).
- `can(q)`: `true` only when this cell answers `q`. It must be `false` for every row of `judge/control.jsonl`
  (prompts the organism already answers: a cell may never shadow a right answer, rule 6).
- `answer(q)`: the text for a person, or `null` when it cannot after all (a null is a miss, never a guess).
- `examples`: `[{ q, expect }]`, the development rows it was grown from, `expect` as below.

`grow/contract.mjs` `validateCell(source, mod)` checks all of it and returns `{ ok, errors: [] }`.

## A candidate directory

`state/grow/gen-<n>/<lane>/<id>/` (runtime, gitignored):

- `cell.mjs`, `test.mjs` (`grow/contract.mjs` `validateTest`: it imports `./cell.mjs`, other `./x.mjs` of its
  directory, and of node only `node:test`, `node:assert`, `node:assert/strict`, `node:fs`, `node:path`,
  `node:url`; it never names `process`, `require`, a dynamic `import()`, `fetch`, `eval`, `new Function` or a
  socket; its pass/fail count is node's own TAP summary on the test child's stdout and holds only when that
  stdout carries exactly one summary, so a summary the file prints itself voids the count), `examples.jsonl`
  (one `{ q, expect }` a line), `brief.md` (what the arm was told; optional);
- written by the runner: `result.json`; by the selector: `verdict.json`.

## expect (judge/judge.mjs `expectOk(got, expect)`)

`{ equals?, contains?: [..], containsAny?: [..], notContains?: [..], minWords?, maxWords?, notRefusal?: true }`.
Text compares trimmed and case-insensitively. `notRefusal` fails on a `got` matching
`/^(?:nothing in memory matches|I do not carry that yet|I am growing a cell)/i` or on `null`.

## result.json (grow/sandbox.mjs; the probe grow/probe.mjs runs INSIDE the sandbox)

```
{ candidate, id, class, backend: "vercel" | "here", session, node, startedAt, wallMs, cpuMs,
  validate: { ok, errors }, tests: { exitCode, passed, failed, tail },
  examples: [{ q, can, got }], heldout: [{ q, can, got, ms }], control: [{ q, can }],
  exitCode, error }
```
The runner sends the held-out rows' `q` only (never `expect`) into the sandbox; the network policy in the
sandbox is deny-all; the probe imports the cell, validates, runs `node --test test.mjs`, then calls
`can`/`answer` per row with a 2000 ms budget per row, and prints the JSON above on stdout, nothing else.

## verdict.json (judge/select.mjs)

```
{ candidate, id, class, survived, why: [..], lockOk, judgeSha,
  examples: { n, ok }, heldout: { n, ok, score }, baseline: { n, ok, score, file },
  control: { n, shadows }, tests: { passed, failed }, at }
```
`survived` is true only when: `lockOk`, `validate.ok`, `tests.failed === 0` and `tests.exitCode === 0`,
`control.shadows === 0`, every example ok, and `heldout.score > baseline.score` (the organism before the
cell, `judge/baseline.mjs`). No other path to true.

## grown/ (the survivors, committed; the function and the CLI import it statically)

- `grown/index.json`: `{ generation, cells: [{ id, class, generation, lane, file, heldout: { score, n }, promotedAt }] }`.
- `grown/index.mjs`: GENERATED by `grow/store.mjs promote`: static imports of `grown/cells/<id>.mjs` in
  index order, `export const GROWN` (the modules) and `export function grownAnswer(q)` returning
  `{ id, class, generation, answer }` from the first cell whose `can(q)` is true and whose `answer(q)` is a
  non-empty string, else `null`. `act/prompt.mjs ask()` calls it right after the conversation region.

## The cell store (j4ydenlxl/brain-cells, cloud only, never cloned)

Written through the GitHub contents API (`gh api` when present, else `GITHUB_TOKEN` with fetch):
- `shards/gen-<n>-<lane>.tar.gz`: the whole lane directory (every candidate, winner or loser, with
  result.json and verdict.json);
- `generations/gen-<n>-<lane>.json`: `{ generation, lane, at, candidates: [{ id, class, survived, heldout, baseline }], cpuMs }`;
- `index.json`: `{ shards: [..], cells: [{ id, class, generation, lane, survived, shard }] }`, appended.

## The miss log (Supabase public.misses)

reads and updates with `SUPABASE_SERVICE_KEY` (his hand, never in chat, never in the repository).
