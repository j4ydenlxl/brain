# his-data (board 23)

## What it was

The gate's HIS DATA row was RED on 2026-09-26: 824 of 825 data files under `bench/fixtures`
were named on a `SOURCES.md` line with a licence; `perception-urls.json` (1854 bytes) was the
one uncovered file, its origin written nowhere.

## Measured

Read, in this order:

- `bench/fixtures/perception-urls.json` in full (1854 bytes): the allow list `bench/perception.mjs`
  reads. Three url entries, each with a hand-written `question` and `why`, one `expect` (a
  fragment of the page title) and one `fact` (a fragment of the page text), plus `hosts`,
  `webPolicy`, `control`, `userAgent` and two prose fields.
- `bench/perception.mjs` (520 lines, a 36-line header comment on lines 1 to 36): it reads the
  fixture and writes `bench/verdicts/perception.json`; it never writes the fixture. A tree-wide
  grep for `perception-urls` found no writer anywhere.
- `bench/verdicts/perception.json` (at 2026-09-18T03:44:42.601Z): for each of the three pages,
  `factInPage` true and the fetched title contains the `expect`, so all six quoted strings are
  verbatim page text (the bar below re-reads this and prints 6 of 6).
- `bench/gate.mjs` lines 276 to 367: `fixtureCoverage` reads ANY `LICENCE_RE` token on a line
  that names a file as that file's licence; `GENERATED_RE` covers a file only when the named
  writer exists in the tree.
- `LICENSE` at the repo root: proprietary, all rights reserved, copyright the owner of
  dilation.dev. MANUAL.md P15: "every byte the organism learns from is public with its licence
  in bench/fixtures or captured by the organism itself", and the row prints bytes of his data.
- `notes/ladder.md` lines 245 to 251: the three root fixtures were written in this repo, and "the
  licence is not mine to choose".
- `test/gate.test.mjs` case (a): the row's existing cases (licence, same licence, directories,
  notices, prefix trap). It has no generated-by case and no fragment-licence case.
- Published way, one page: the REUSE 3.3 specification (reuse.software/spec-3.3). Every covered
  file must carry its own licensing information, and a snippet quoted from elsewhere is licensed
  with `SPDX-SnippetBegin`/`SPDX-SnippetEnd` and its own identifier, which applies to that
  snippet only, never to the whole file.

What the first pass got wrong, and what this pass did:

1. It wrote "CC BY-SA 4.0" on the `perception-urls.json` line. That is the licence of the
   Wikipedia fragment (a snippet), not of the file. The gate read it as the whole file's
   licence and printed GREEN 825 of 825 and "bytes of his data 0", while the same line said the
   file was hand-authored in this repo. The rest of the file is under the repo's own
   all-rights-reserved LICENSE, and choosing an open licence for it is the owner's call. The line
   now names no licence token and no generated-by clause (no script writes the file).
2. It said the only external bytes were the three `expect` fragments. The three `fact` fields
   are quoted page text too: "This domain is for use in documentation examples" (example.com),
   "comprehensive map of neural connections" (Wikipedia, Connectome), "JavaScript runtime"
   (nodejs.org). The line now quotes all six, 154 bytes of text.
3. It added a comment block to `bench/perception.mjs`, a file this item does not own (the item
   owns a header comment only in the tool that generated the fixture, and no tool generates
   it). Those six lines are removed; `git diff -- bench/perception.mjs` is empty.
4. It wrote no verdict. The bar below writes `bench/verdicts/his-data.json`.
