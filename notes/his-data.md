# his-data (board 23)

## What it was

The gate's HIS DATA row was RED on 2026-09-26: 824 of 825 data files under `bench/fixtures`
were named on a `SOURCES.md` line with a licence; `perception-urls.json` (1854 bytes then) was
the one uncovered file, its origin written nowhere.

## How it is covered now

The allow list is configuration the perception bench needs, not data anyone downloaded. The
orchestrator (commit cebc2dd, after verify2) moved it into `bench/perception-urls.mjs` as code;
the fixture is that file's output (`node bench/perception-urls.mjs` writes it, `--check` exits 1
on drift). Line 5 of `bench/fixtures/SOURCES.md` carries the clause `generated by node
bench/perception-urls.mjs`, names the six fragments quoted from the three public pages, and
claims no licence token for the file. `bench/his-data.mjs` computes the row through the gate's own
exported `fixtureCoverage` and `hisDataRow` and writes `bench/verdicts/his-data.json`.

## Control

The GREEN for `perception-urls.json` rests on one clause and a writer that exists. Four arms,
each a scratch dir holding the real `SOURCES.md` (line 5 varied) and the fixture:

```
control real: covered true, licence generated by bench/perception-urls.mjs, writer check true, row GREEN, uncovered bytes 0
control noClause: covered false, licence none, writer check true, row RED, uncovered bytes 1945
control ghostWriter: covered false, licence none, writer check true, row RED, uncovered bytes 1945
control drifted: covered true, licence generated by bench/perception-urls.mjs, writer check false, row GREEN, uncovered bytes 0
```

Taking the clause away, or pointing it at a writer that does not exist, turns the row RED, so the
GREEN measures the clause and the writer, not a stray token. The drifted arm shows what the census
cannot see: it never compares bytes, so a hand-edited fixture stays covered, and only the writer's
own check (`--check`, `fixtureMatches`) catches it. The first pass's control (the CC BY-SA 4.0
token appended to a hand-authored line reads as covered) is pinned by case one of the test.

Tests: `node --test test/his-data.test.mjs test/perception-urls.test.mjs` prints pass 6, fail 0.
This pass added the third case of `test/his-data.test.mjs`, the four control arms above as
assertions.
